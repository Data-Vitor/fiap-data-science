# FIAP - Data Science

Repositório com meus estudos, exercícios e materiais do curso de Tecnologia em Data Science na FIAP, organizados por matéria. O foco é registrar a evolução prática ao longo da graduação, com ênfase em programação e estatística aplicada a dados.

## Estrutura

### building-data-driven-apps
Lógica de programação e fundamentos com Python. Exercícios de estruturas de controle, funções e manipulação de dados, servindo de base para as aplicações orientadas a dados.

### statistical-methods-for-data-science
Métodos estatísticos aplicados à ciência de dados. Matéria voltada à estatística descritiva e inferencial, com aplicação prática dos conceitos em Python.

### nemec-estatistica
Estudos por conta própria a partir do material do professor de Estatística, indo além do conteúdo de sala. Reflete meu interesse específico pela área estatística dentro de Data Science.

## Tecnologias

- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Estatística descritiva e inferencial

## Sobre

Estudante de Data Science na FIAP, em formação na área de dados com interesse forte em estatística e analytics. Este repositório acompanha minha jornada de aprendizado ao longo do curso.
